These are the current design presentations for CareLink 0.2.0. Slides 1, 2, 6 and 9 were revised from the supplied v2 analysis to reflect Windows desktop delivery, the embedded Fastify service with a private protocol, persistent Chinese/English switching and five-person iterations. Each deck retains nine slides and editable content, including the original table.

The detailed [architecture](../ARCHITECTURE.md), [iteration plan](../ITERATION_PLAN.md) and [delivery status](../DELIVERY_STATUS.md) define the implementation and verification evidence. Identical deck copies are provided in the parent workspace's `output` folder; the v2 decks remain historical references.

Both packages passed integrity and layout checks, and all 18 slides were rendered and visually reviewed. Microsoft PowerPoint itself was unavailable for validation. The rendering tool showed minor font clipping in two unchanged English footer lines; their underlying text and geometry remain preserved from the source deck. Check those footers in the team's presentation environment before projecting or exporting to PDF.
