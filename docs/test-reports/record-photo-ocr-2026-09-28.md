## 功能和兼容证据

- 真实引擎识别合成中文印刷病历图片，并提取主诉、现病史、诊断等明确标题字段；没有用固定返回值代替端到端 OCR。
- 浏览器测试验证模型与 WASM 从本地加载，并阻止与检查外部 HTTP 请求。桌面在 Electron session 离线状态运行真实识别，保存后完整退出重启，再验证病历内容和版本。
- 患者未选择时禁止入口；只读病历不显示入口。既有标题、诊断默认保留；只有勾选字段与患者内容确认后才填入。保存仍调用原有接口，图片不包含在请求中。
- 切换患者/模板、手动修改原字段、取消识别、卸载、延迟到达的识别结果或摄像头授权均有回归测试。
- 图片格式、空图、12 MB 上限、4,000 万像素上限、缩放、损坏图片、模型失败、120 秒总体超时、图片编码等待期间取消、Worker 清理均有测试。
- 使用 Chromium 虚拟摄像头进行真实 getUserMedia 和抓帧，拍摄后轨道停止；权限拒绝时能上传图片，手动草稿保留。另检查 390px 宽度与英文入口。
- 桌面既有登录隔离、SQLite 持久化、审计 CSV 下载、重启和双语导航验收全部通过。
- 未增加数据库迁移；患者/问诊/医嘱/认证等生产模块未修改。只为 OCR 增加必要的本地 Worker、WASM MIME 与专属 Worker CSP。

## 验收中处理的问题

1. 审查发现最初超时没有覆盖图片准备阶段，已将计时覆盖整个流程，并测试图片解码不返回、canvas 编码阶段取消。
2. 构建脚本最初放在前端目录被原有模块边界检查拦截；已移到仓库 scripts，保留原边界规则。
3. 全量浏览器首次结果为 22 / 23，旧首页用例仍断言已经过时的“框架演示”文案。确认首页与该测试在本次基线已不匹配，仅将测试对齐现有“本地业务演示 · 合成数据”提示，未改首页业务；复跑 23 / 23。
4. Playwright 的请求观察无法捕获桌面自定义协议的嵌套 Worker 资源；桌面用例改用禁用网络的实际识别/保存/重启验证，浏览器仍保留具体本地资源请求断言。
