## 2. 核心行为变化

**审计与资料。** 旧资料 localStorage 无法确认属于谁，故不自动迁移，改为读取当前会话的数据库记录。资料和审计同事务，审计失败时回滚；邮箱不接受普通资料更新。审计不再仅在最近 100 条中前端过滤；查询和 CSV 使用同一组服务端条件，默认分页 20 条，导出最多 50,000 条，超限明确拒绝而不静默截断。CSV 防表格公式注入，操作日志不写密码、令牌、照片或临床正文。

**授权与任务。** 会诊临时授权仍受患者、医生角色、活动任务、成员状态、期限和撤销共同约束。仅有临时阅读权限不能再邀请其他医生扩散访问权。结束、报告生成与撤权使用事务，失败不留半完成状态。完成后界面退出房间；后台刷新发现失权，清理已加载的讨论/图片/输入，展示原因。

**提醒与偏好。** 新任务记录创建医生；调度在批次限制前排除无权限任务，避免前 25 条失权旧任务堵住整个队列。每个提醒最多自动尝试 3 次、失败后至少间隔 1 分钟；pending 超过 5 分钟可恢复。回执以提醒 ID 唯一，正文在投递时保存。医生偏好控制医生侧提示，患者测试收件箱不因该开关丢失。设备弹窗不包含患者详情，也不会因系统 Notification API 报错而阻断站内内容。

**运行与安全。** 浏览器实时连接改为真实会话子协议认证，注销/失效后关闭；桌面 IPC 同样已对每次实时投递重新校验会话，并防止切账号的异步订阅交错。修复 image-size 已知拒绝服务依赖风险，当前锁定 2.0.4。本次 npm audit 输出无已知漏洞，不表示完成全面安全认证。
